Scope every PR.

Requirement → backlog → PR plan → PR order. Agents get a defined scope and a traceable brief — never the whole repository.

Don't rerun the world.

Targeted tests per PR, integration QA per merge, full regression at the gate. Fast where it's safe, thorough where it counts.

Mocks aren't proof.

Green suites are the start. Then real QA against real providers — auth, models, tools, sessions, and the failure paths.
